# North Star Bakery Touchstone 4
Continues Touchstone 3. Includes four HTML pages, styles.css and script.js.

1. Add Sophia Bakery_c.zip assets to media/ using their original filenames.
2. Upload files to your existing GitHub project and commit/push.
3. Start an HTTP server in Codespaces: python3 -m http.server 8000
4. Open forwarded port 8000. Save/remove products on products.html, refresh, and confirm restoration.
5. Submit the contact form empty, correct the errors, and check the success message. The demo sends no order.
6. Capture the three screenshots requested by the Word template, add actual public repository and IDE preview URLs, and test mobile/desktop layouts.

Only product IDs are stored in localStorage. Contact information and allergy notes are not stored. Media is not bundled because Sophia's download was unavailable.
